Data & Laporan

Impor, cadangan, dan cetak laporan

Unggah Massal

Impor data buku atau murid dari file CSV / Excel (.xlsx).

Cadangan Data

Unduh seluruh data (buku, murid, sirkulasi) sebagai file JSON, atau pulihkan dari file cadangan.

Cetak Laporan

Gunakan tombol Cetak pada halaman Murid, Buku, atau Sirkulasi untuk membuat laporan rapi.

Pengaturan Sirkulasi

Data Contoh

Buat 12 transaksi contoh (termasuk yang terlambat) untuk mencoba grafik dan denda.

Reset Data

Kembalikan ke data awal dan hapus seluruh riwayat sirkulasi.

Tambah Murid
